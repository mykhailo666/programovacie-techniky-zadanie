# Programovacie techniky - Zadanie

University assignment for the course **Programovacie techniky** (TUKE) taught by doc. Ing. Kamil Židek, PhD.

## Project Description:
- **GUI Application:** Built using Python and `tkinter`.
- **Features:** 
  - Array input handling and error validation (checking for empty fields and non-numeric characters).
  - Random number generator for array elements.
  - Custom Bubble Sort algorithm (`triedenie poľa`).
  - Statistical calculations (Min, Max, Sum, Average).
- **Compilation:** Supports building a standalone `.exe` via PyInstaller.# programovacie-techniky-zadanie
